# The App Factory Course (v1, 23 Oct 2026)
One master course on how Lisa's App Factory takes an idea through gates to a live, marketed, monitored app. Three cuts: Track F (family learners), Track B (business keynote) and the Reseller version. Brand: LJR7. Set 3 years ahead ("Vision 2029 · Illustrative"). All businesses, people and figures are invented.

**Start here:** `INDEX.csv` (every asset and its editable source) · `SYLLABUS.md` · `STAGE0-PROPOSAL.md` · `QUESTIONS.md` · `CLASHES.md`

| Folder | What |
|---|---|
| `glossary.json` | The ONE file for every name, colour and number |
| `scripts/` | Module scripts (M00-M10), keynote and partner scripts, framework map |
| `slides/` | Keynote, partner cut, 11 Track F decks (PPTX + PDF); drag a PPTX into Canva to edit it there |
| `graphics/` | Course graphics (SVG source + PNG), recap cards, codes cards |
| `vision2029/` | Factory dashboard from the real `factory/` page, Pulse, app detail, launch and operate |
| `apps/` | Sample app screens and the white-label page |
| `video/` | Remotion video system, rendered MP4s, captions, storyboards, voice-over text |
| `workbook/` | Workbook PDF, DOCX and Kindle EPUB |
| `cf-pack/` | ClickFunnels lesson pack |
| `reseller/` | How the brand jacket works (Puppy Classroom worked example) |
| `qa/` | `check.py` (the done test), scorecard |

Rebuild everything: `bash build.sh` (videos: `node video/render.mjs`). Check: `python qa/check.py`.
Sources were read from Lisa's Drive and are **not** stored here; this repo is public.
