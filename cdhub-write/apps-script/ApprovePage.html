Edit an entry (owner only)

Overwrites a wrong entry in place. No record of the old value is kept by this system. Staff cannot do this: they can only add rows, and they tell you about a wrong entry.

Staff codes (owner only)

Switch off the code of someone who has left. It stops working at once for reading and saving. The entry stays in the list and the switch-off is noted in the approvals queue file. The code itself is never shown here.

Inspector links (owner only)

A link an inspector opens with no login. It shows only the dogs and fields you tick, never scores, and it cannot save anything. It ends by itself after its last day, or when you press Stop.
